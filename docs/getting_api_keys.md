## How to get langsmit api key

- go to https://www.langchain.com/langsmith-platform (create a account).
- go to langchain dashboard https://smith.langchain.com/
- create a new project with name "Next-AI". (Recommended to do that).
- go to the project and generate your api keys and past in `.env` file (make sure to use the same name as mention in `.env.example` file)
